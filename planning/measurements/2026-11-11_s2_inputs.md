Assumptions (the file records none of these):

- **Topology linear** (`circular: []`). FASTA carries no topology, the headers carry no flag, and S1 was
  built the same way. Many of these genomes are probably complete circular or terminally redundant
  assemblies; stored as linear, a gene across the sequence's start or end is cut in two (partial
  genes at both ends) rather than called across the origin. *Not measured.* A per-genome topology would
  need the collection's own metadata (not in the Figshare record).
- **Gene calling `gv-meta`**: `kind` virus makes `genecall._finder` use `pyrodigal_gv.ViralGeneFinder
  (meta=True)`, the mode the ladder and `rN.1a` used for S1 ("gene calling in mode `gv-meta`",
  `2026-11-10_rebuild_10gbp.md`, branch `build/r10`). `genetic_code` 11 is the field's value only:
  meta modes report the code per gene (`GenomeInput` docstring), which matters here because alternative
  codes (for example code 15, TAG reassigned) are common in huge phages.
- **`assembly_quality` complete**, as S1. The collection is called "non-redundant", which may mean
  dereplicated representatives (`vOTU` is a value the schema allows); the file does not say. A decision
  for the PI before H1 is built.
- **One genome per record**: 7,230 distinct ids, the collection's 7,230 genomes; a later preprint calls
  43 of them non-viral (`sources.yaml` note); they were not identified or removed.

### Dry check: do the inputs load

`bio-box stage inputs` has **no dry-run flag**. It parses `--genomes` with `biobox.cli._genomes` (JSON to
`GenomeInput`), then `l0seq.inputs.write_genome_input` refuses a written partition, validates in `_rows`
(no contig twice in a genome, circular contigs inside their genome, no contig in two genomes) and
writes. `s2_check_inputs.py H1 inputs/H1/genomes.json inputs/H1/objects.json` runs only the parsing and
`_rows`, plus `cli._source_objects` (how `stage ingest` reads `--objects`), `catalog.check_stages(["H1"])`,
the `genome_input` schema's enums and `genecall._finder` for the mode. It never calls
`write_genome_input` and opens no root. Result (`H1/h1.log`), exit 0:
